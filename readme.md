# Global Layoffs Data Analysis (EDA Project)

## CodeAlpha Data Analytics Internship — Task 2

This project focuses on performing Exploratory Data Analysis (EDA) on a global layoffs dataset using Python. The goal of this project is to analyze layoff trends across different companies, industries, and countries and generate meaningful business insights through data analysis and visualization.

---

# Objective

The objective of this project is to:
- Clean and preprocess raw data
- Explore dataset structure
- Identify patterns and trends
- Create visualizations
- Generate business insights from layoffs data

---

# Dataset Used

Dataset: Global Layoffs Dataset (2020–2025)

Source:
https://www.kaggle.com/datasets/swaptr/layoffs-2022

---

# Tools & Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code
- Jupyter Notebook

---

# Project Workflow

1. Imported required Python libraries
2. Loaded the dataset using Pandas
3. Explored dataset structure and columns
4. Cleaned missing and null values
5. Performed Exploratory Data Analysis (EDA)
6. Created visualizations and charts
7. Generated key insights from the data

---

# Analysis Performed

The following business questions were analyzed:
- Which companies had the highest layoffs?
- Which industries were most affected?
- Which countries recorded maximum layoffs?
- How did layoffs change over time?
- What trends can be observed globally?

---

# Visualizations Used

- Bar Charts
- Pie Charts
- Line Charts

These visualizations helped in understanding trends and comparisons effectively.

---

# Key Insights

- Tech companies experienced the highest layoffs.
- United States recorded maximum layoffs globally.
- Layoffs increased significantly during economic slowdown periods.
- Several funded startups also reduced workforce.
